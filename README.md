# 🎓 Grabit-LMS

Grabit-LMS is a full-stack Learning Management System (LMS) built using a modern **client-server architecture**, enabling efficient course management and user interaction.

---

## 🚀 Overview

This project demonstrates a scalable full-stack application with a React-based frontend and a Node.js backend, focusing on real-world LMS functionality.

---

## ✨ Features

* 🔐 User Authentication (Login / Register)
* 📚 Course Management System
* 🧑‍💻 Admin Dashboard
* 📝 Mock Tests & Result Pages
* 🔄 REST API Integration
* ⚙️ Modular Client–Server Structure

---

## 🛠️ Tech Stack

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```
git clone https://github.com/G1A2Y3U4/Grabit-LMS.git
cd Grabit-LMS
```

### 2️⃣ Install Dependencies

#### Frontend

```
cd Client
npm install
```

#### Backend

```
cd Server
npm install
```

---

### 3️⃣ Run Application

#### Start Backend

```
cd Server
npm run dev
```

#### Start Frontend

```
cd Client
npm start
```
